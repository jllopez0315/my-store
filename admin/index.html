Store Admin needs two settings

This page is not connected to a database yet. Open index.html in a text editor and find the ADMIN_CONFIG block near the top of the script.

  1. In Supabase, open your project, then Project Settings > API.
  2. Copy the Project URL into supabaseUrl.
  3. Copy the anon public key into supabaseAnonKey.
  4. Set storeName to the name you want in the header. storeUrl is optional: your store's address, for the "Open my store" link.
  5. Save the file and reload this page.

Have you run setup.sql in the Supabase SQL Editor and added your owner user under Authentication > Users? Both need to happen once before the first login.

    Video
    or paste an address

    MP4 (H.264) with no sound track, 6 MB at most. 1280 by 720 or 1920 by 1080 pixels, 8 to 15 seconds, made to loop. Under 4 MB plays smoothly on phones. The picture above is the still frame shown while it loads. A video uploaded here is served from your database's storage, which has a monthly traffic allowance (5 GB on the free plan). For a busy store, ask Claude to put the file in your store's img folder instead, where your host serves it free.
